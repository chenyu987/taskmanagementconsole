# 0001 统一节点树与按工作区继承的权限

日期：2026-11-25 · 状态：已采纳

## 背景

需求从「项目 → 任务」改为无限层级的统一节点树，私人人生事务和 EverHarvest 团队工作放在同一棵树里，cxuq 只能看到团队部分。

## 决定

- 一张 `nodes` 表承载所有层级，`type` 只是标签。
- `ancestorIds`（祖先链）+ `path`（可索引的路径字符串）+ `depth`。Convex 索引不支持数组包含查询，子树查询用 `path` 前缀范围。
- 每个节点属于一个工作区，权限只看工作区成员资格；工作区根节点可以挂在别的工作区下，但父空间成员必须 ⊆ 子空间成员。
- 所有返回给前端的节点经过 `redactNode` 裁剪祖先信息。

## 后果

- 移动子树需要批量改写子孙的 `ancestorIds` / `path` / `depth`，子树很大时分批调度。
- 想在团队任务下记「只有自己看得到」的备忘，需要另行设计（不能直接挂私人节点）。
